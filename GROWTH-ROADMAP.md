# LinkGlimpse Growth Roadmap

## In progress: topical authority and product moat

- Own the Open Graph checker/test/validator keyword cluster.
- Publish focused troubleshooting and implementation pages.
- Make reports shareable, comparable, actionable, and easy to hand to an AI coding agent.
- Measure successful checks, exports, shares, remediation copies, AI prompt copies, and comparisons.

## Deferred: distribution phase

Do not execute this phase until the product and content changes have been indexed and measured.

- Publish an npm package that exposes useful LinkGlimpse metadata checks and links to the canonical website/docs.
- Publish a Chrome extension for inspecting the current tab and earning a Chrome Web Store listing/link.
- Publish the same browser extension for Firefox Add-ons.
- Add relevant developer-tool directories, GitHub lists, technical tutorials, and newsletters.
- Prioritize relevant referring domains and product usage over raw backlink count.
