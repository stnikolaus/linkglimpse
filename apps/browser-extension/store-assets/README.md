# Browser marketplace assets

Generated listing graphics for the Chrome Web Store and Firefox Add-ons:

- `promo-440x280.png` — Chrome small promotional tile.
- `screenshot-social-1280x800.png` — automatic audit and social preview.
- `screenshot-serp-1280x800.png` — Google SERP preview.
- `screenshot-fixes-1280x800.png` — actionable checks and AI-ready fixes.

The browser-rendered source is kept in `source.html` so the images can be regenerated when the popup changes.
The packaged 128px marketplace icon uses the transparent-padding variant at `../src/icons/icon-128-store.png`.
